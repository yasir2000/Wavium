# Wavium Examples

This directory contains small, focused examples that demonstrate the primary Wavium programming model.

Each example is intentionally narrow and maps to one subsystem or workflow:
- [hello-component](hello-component)
- [actor-supervision](actor-supervision)
- [binary-rpc-replacement](binary-rpc-replacement)
- [edge-device-sensor](edge-device-sensor)
- [gpu-exec](gpu-exec)
- [ai-agent-component](ai-agent-component)

Examples should emphasize component-first execution, WIT contracts, and capability-scoped runtime access.
