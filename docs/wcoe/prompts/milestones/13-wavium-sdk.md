# Prompt 13 - Wavium SDK


```text
Create the Wavium SDK.


Goal:

Developers should build applications without knowing runtime internals.


Create:


sdk/

├── zig/
├── rust/
├── c/
└── examples/


Provide:

- component templates
- WIT bindings
- actor APIs
- capability APIs
- build integration


Create:

wavium new

wavium build

wavium package

wavium deploy
```
