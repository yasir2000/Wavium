# Configuration Reference

Document the configuration model used by the runtime, bootloader, build system, and CLI.

## Expectations

- configuration should be explicit
- version configuration where necessary
- align configuration with hardware profiles and package metadata
- avoid hidden defaults that change behavior silently

Configuration should be explicit, versioned where necessary, and aligned with hardware profiles and package metadata.
