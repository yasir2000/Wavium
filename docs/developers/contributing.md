# Contributing Guide

This page summarizes the project-wide contribution workflow.

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for the authoritative rules.

## Contributor Expectations

- update docs when behavior changes
- add tests for new runtime or hardware logic
- keep changes scoped to a single subsystem when possible
- run the repo scripts before review
- preserve architectural boundaries

## Review Focus

Maintainers should check for:
- correctness
- security implications
- documentation coverage
- alignment with the subsystem spec
