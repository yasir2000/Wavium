# Getting Started

To work on Wavium:
1. read the architecture and specifications
2. use the scripts under [scripts](../../scripts)
3. run the repo CI wrapper
4. make changes with tests and docs together

## Contributor Path

1. choose a subsystem
2. read the matching docs and ADRs
3. make a small change
4. run validation
5. update the docs portal if behavior changed

The project is organized around explicit subsystems, so new contributors should start by choosing the subsystem they are working on.
