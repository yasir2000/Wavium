# Diagram Sources

This directory stores the source for architecture and flow diagrams used across the documentation set.

## Recommended Approach

- keep Mermaid sources alongside the docs that reference them
- export SVG or PNG only when static assets are required
- prefer versioned text sources for reviewability
- update diagrams when architecture or workflows change
